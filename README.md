# 🤖 Bot WhatsApp Multi Atendimento

![Preview](./preview.png)

Sistema de atendimento automatizado para WhatsApp utilizando Node.js e whatsapp-web.js.

---

# 🚀 Funcionalidades

- Atendimento automático
- Sistema de múltiplas sessões
- Menu interativo
- Respostas automáticas
- Separação de clientes
- Armazenamento em JSON
- Integração com WhatsApp Web

---

# 🛠 Tecnologias

- Node.js
- JavaScript
- whatsapp-web.js
- JSON
- Git/GitHub

---

# ▶️ Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/Gui-94/whatsweb.git
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
node server.js
```
